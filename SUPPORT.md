# Support

- **How do I…?** The [guide](docs/guide.md) covers setup, the keys, worktrees, agents and the commands; the [README](README.md) has the quick start.
- **A bug or an idea:** open an [issue](https://github.com/sanagnos/taskman/issues/new/choose) with the bug or feature template. Say which taskman version (`taskman --version`), OS and CLI (`claude --version` or `codex --version`) you're on.
- **A security problem:** don't open an issue; report it privately as [SECURITY.md](SECURITY.md) says.

taskman is maintained in spare time, so an answer can take a few days.
